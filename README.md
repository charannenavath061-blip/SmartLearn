# SmartLearn

A web-based learning management system designed to support students and teachers.

## Features

- Student registration and login
- Teacher registration and login
- Student dashboard
- Teacher dashboard
- Course management

## Technologies Used

- JavaScript
- TypeScript
- Node.js
